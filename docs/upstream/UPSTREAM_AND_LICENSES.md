## REA reference

The separately reviewed repository is [morluto/rea](https://github.com/morluto/rea). Its README describes an agent/MCP toolkit for evidence-based reverse engineering of websites, JavaScript/Electron apps, native binaries, and other software. The repository is MIT-licensed but is not bundled in this application.

REA can be used as an optional development-time research tool for a website that the operator owns or has permission to inspect. It is not the product's prompt collector, does not replace the configured answer/search providers, and is not needed to build or run this application. Follow REA's current installation, authorization, and license instructions if adopting it separately.
